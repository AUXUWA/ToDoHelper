      鉴权状态未知

      设备开启鉴权后，所有请求（包括读取列表这类 GET）都要带请求头 X-Auth-Token； 实时推送那条长连接也会带上同一个令牌。令牌只保存在本机浏览器的 localStorage 里， 不会发往设备以外的任何地方。
      下面两个按钮会改设备上的鉴权状态：「让设备用这个令牌」把填好的令牌写进设备 （写完起，设备上包括读取在内的每个请求都要带它）；「关闭设备鉴权」把设备恢复成 不校验。改了之后本页会自动用新的令牌重连。设备自己的「设置」页也能生成/关闭令牌，两边等效。

      墨墨背单词（开放 API）

      状态未知

      墨墨没有公开的第三方登录，需要在手机上取一个 开放 API 令牌： 「墨墨背单词 App → 我的 → 设置 → 开放 API」生成后填到下面即可。
      令牌是只写的 —— 填进来之后设备只会回一个打码的提示（如 g_zV****）， 本页永远不会把完整令牌显示出来，也不写进 localStorage。

      令牌能力探测

        「保存并校验」会带着令牌当场访问一次墨墨接口，正常需要 5–15 秒，请耐心等按钮恢复。 校验失败不一定代表令牌无效 —— 只有学习权限的令牌读不到助记 / 例句，属于正常现象， 用上面的「探测令牌能力」可以看到逐条结果。
        关于「回传学习情况」：墨墨开放 API 没有提交复习评分的接口， 所以设备上背完的词不会让墨墨 App 的「今日 N/M」增加。开启上面的开关后， 设备会把学过的词用 advance_study 排回复习计划，让云端继续安排它们。

            语音（云端识别 / 合成）

            设备本地不做语音识别（没有离线识别模型），识别与合成都走你自己指定的 云端端点。协议：
            · 识别（ASR）：POST 端点，body 是原始 PCM（16 kHz / 16 bit / 单声道）， 期望返回 {"text":"识别结果"}；
            · 合成（TTS）：POST 端点，body 是 {"text":"要念的内容"}， 期望返回 audio/pcm（16 kHz / 16 bit / 单声道）。
            端点没配的时候，设备就只走文字：识别那半边会提示不可用，合成那半边安静跳过。
